# Contributing to DropFlow

DropFlow welcomes fixes, tests, accessibility improvements and documentation.
Discuss large architectural changes before implementing them, and keep desktop
and Android release/version streams separate.

By intentionally submitting a contribution for inclusion, you agree to license
your contribution under Apache-2.0, as described in section 5 of [LICENSE](LICENSE),
unless you explicitly state otherwise before submission. Only submit work you
have the right to contribute. No copyright assignment is required.

Preserve existing copyright and third-party notices. New images, fonts, icons
and other external assets must include their source, license and attribution.
Do not add signing keys, passwords, tokens, local settings or private user data.

Follow the current development and validation commands in [README.md](README.md)
and [docs/RELEASE.md](docs/RELEASE.md). Report what was actually tested; an
emulator/build result is not proof of physical-device interoperability.
