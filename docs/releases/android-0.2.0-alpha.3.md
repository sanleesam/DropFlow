### Experimental: Nearby Link lab

Open **Settings → Updates → Open Nearby Link lab** and enter the temporary
credentials from the Windows Development preview. Android 12+ and support for
a second local-only Wi-Fi connection are required. The Android prompt, if shown,
is for that temporary connection; do not join the test network in system Wi-Fi
settings.

This is a hardware test, not a file-transfer mode. It verifies 16 MiB of
synthetic data each way and stops if it detects a change to Android’s default
connection. Keep an internet stream active on both devices during the test.
Mac is not supported by this lab. Existing shared-network transfers remain
available, and this update does not introduce a cloud service.
